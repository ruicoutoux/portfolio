01. The Problem: Asset Vulnerability Across Fragmented Consoles

As enterprise clients scaled their low-code and microservice modules, public API endpoints and shared UI elements were exposed without central auditing. Development teams inadvertently published internal assets to public scopes, creating security compliance risks and operational ambiguity.

Midway through defining the governance model, a major organizational restructuring threatened to shelve the project. Traditional static Figma mocks failed to convey the technical feasibility and instant security value to incoming executive leadership.

⚡

Critical Architectural Trade-off: Code-Level AI Prototype vs. Static Design Decks

Rather than refining static slide decks, we paired with PMs to build a working, code-level AI prototype demonstrating live asset defense.

The Tension: Static design decks were easy to produce but failed to eliminate executive skepticism regarding architectural latency and real-time policy evaluation overhead.

The Resolution: As Lead UX DRI, I pivoted the team to build an interactive functional prototype using AI coding workflows. This allowed executives to test real-time asset discovery, policy enforcement checks, and instant rule validations in a live sandbox environment.
